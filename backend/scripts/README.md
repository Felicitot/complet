# Scripts exécutables depuis l'interface

Placez ici vos scripts (`.js`, `.py`, `.sh`). Ils apparaissent alors dans
Scripts & Tâches → « Nouvelle tâche ». Ils sont lancés **sans shell**, avec
les arguments saisis, un délai maximal, et uniquement depuis ce dossier.

Variables d'environnement fournies : `RIVOTRA_DATA_DIR`, `RIVOTRA_DATE`.
Code de sortie 0 = succès, autre = échec.
